THREE ERAS: INSTALL ON IPHONE (works offline after the first visit)

The game needs to be at a web address once. After you add it to your
Home Screen it opens like an app and plays with no internet.

1. Put these files online (pick one):
   GitHub Pages (free, permanent):
     a. Make a free account at github.com.
     b. Create a new public repository, for example "three-eras".
     c. Add file > Upload files: upload every file in this folder
        except INSTALL.txt (index.html, sw.js, manifest.webmanifest
        and the three .png icons). Commit.
     d. Settings > Pages > Branch: main, folder: / (root) > Save.
     e. After a minute your game is at
        https://YOUR-NAME.github.io/three-eras/
   Netlify Drop (on a computer): go to app.netlify.com/drop and drag
   this folder in. It gives you an https address straight away.

2. On your iPhone, open that address in Safari.
3. Tap Share, then Add to Home Screen.
4. Open the game from the new icon once while online. From then on it
   works offline.

Progress: the app keeps its own save. To bring your progress across,
open the online game, tap Save backup on the title screen, Copy code,
then in the app tap Save backup, paste it and choose Merge.

Updating: upload the new files over the old ones. The app picks up the
new version the next time it opens while online.

Note: a public GitHub repository means anyone with the address can
open the game.
